# NAHOFIT.LIFE — página de Nahomy

Página estática (sin base de datos) publicada en GitHub Pages en **nahofit.life**.

- Botón flotante y enlaces de WhatsApp: (385) 230-0315.
- El formulario "Agenda tu primera sesión" manda los datos a **Fitorbe**
  (`https://fitorbe.com/api/contacto`, coach `nahofit`). Nahomy los ve en su panel de Fitorbe → Solicitudes.
- "Entrar a mi cuenta" lleva a `https://fitorbe.com/login`.
- Cada cambio en `main` se publica solo (`.github/workflows/publicar.yml`).
